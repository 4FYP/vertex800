VERTEX800 – ALL-IN-ONE GODADDY FOLDER
=====================================

This folder IS the website. Upload only this folder's contents.

HOW TO USE ON LOCALHOST (XAMPP / WAMP)
--------------------------------------
1. Copy this whole "godaddy-site" folder into htdocs
2. Open: http://localhost/godaddy-site/
3. Styles and pages load automatically (relative paths)

HOW TO UPLOAD TO GODADDY
------------------------
1. File Manager → public_html → Revamped_Site
2. Delete old files inside Revamped_Site
3. Upload EVERYTHING from inside this godaddy-site folder:
     index.php
     about.php
     contact.php
     ...all other .php files
     assets/
     includes/
     .htaccess
4. Open: https://vertex800.com/Revamped_Site/

Just PHP + HTML + CSS + JS.
